# 🌐 CampusFeed  
### *A Centralized Campus Event Management System for Nepal*

---

## 📌 Overview

**CampusFeed** is a desktop-based event management application designed to centralize information about academic and technological events across Nepalese campuses.

In many institutions, event details are scattered across platforms like WhatsApp, Facebook, and emails, leading to missed opportunities and poor communication.

> 💡 CampusFeed solves this by providing a **single, structured platform** for discovering and managing campus events.

---

## 🚀 Features

### 👨‍🎓 For Students
- Browse all upcoming events in one place  
- Search and filter events (by category, date, organizer)  
- View detailed event information  
- Mark interest (Interested / Not Interested)  

### 🧑‍💼 For Organizers
- Create and publish events  
- Edit and delete events  
- Reach a targeted student audience  

### 🔐 Authentication
- Secure login with institutional email  
- Role-based access (Admin / Student)  

### 🔔 Notifications
- Alerts for new and upcoming events  
- Stored notifications accessible within the system  

---

## 🎯 Problem Statement

- Event information is **fragmented across platforms**
- Students often **miss valuable opportunities**
- Organizers struggle to **reach the right audience**
- Communication is **unstructured and inefficient**

👉 **CampusFeed provides a centralized and reliable solution.**

## 🏗️ Tech Stack

| Layer | Technology |
|------|-----------|
| 💻 Language | C++ |
| 🎨 GUI | Qt 6 |
| ⚙️ Backend | Crow Framework |
| 🗄️ Database | SQLite 3 |
| 🏛️ Architecture | Layered (Presentation + Application + Data) |

---

## 🧩 System Architecture

CampusFeed follows a **3-layer architecture**:

- **Presentation Layer** → Qt-based User Interface  
- **Application Layer** → Crow-based Backend Logic (REST APIs)  
- **Data Layer** → SQLite Database  

✔️ Modular  
✔️ Maintainable  
✔️ Scalable
